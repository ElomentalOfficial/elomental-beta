# elomental-beta

The beta site of Elomental: **https://beta.elomental.online**.

Nothing to edit here. `.github/workflows/deploy.yml` builds the `beta` branch of
[ElomentalOfficial/elomental](https://github.com/ElomentalOfficial/elomental) against the beta
Supabase project and publishes it to this repository's GitHub Pages, within about 10 minutes of a
push to `beta` (or at once with Actions > Deploy beta.elomental.online > Run workflow).

How beta and live fit together: `docs/BETA.md` in the main repository.
